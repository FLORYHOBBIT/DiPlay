# DiPlay AION v0.2.22-aion.1

首个 AION 发行版，基于 DiPlay 0.2.22，面向埃安 Android 8.1 车机。实车验证机型为 G6SA_r8a7796，固件 GAC_A29_AVNT_02_31.59_220908_R。

## 功能与修复

- 蓝牙连接后直接启动 DiPlay，并独立执行自动关闭同步音频的规则，无需车机助手转发。
- CarPlay 歌曲信息、封面和地图直接同步到原车仪表；将相关开关整合进设置页，统一 AION 设置样式。
- 恢复车机热点自动开启的开关入口和初始化逻辑，使用现有的车机热点连接方式。
- 音乐采样率改为每次连接前读取音乐输出通道的原生采样率，再与手机协商；不按车型强制使用 44.1 或 48 kHz。查询失败或遇到未实现的协议采样率时，声明已支持的格式供手机选择，并记录原因。
- 为 AION 音乐流增加有界 RTP 排序，保留缓冲策略并关闭造成声音变速的时钟微调。
- 车机图标名称默认使用 AION，保留自定义图标；移除多余的权限工具页。
- 安装包仅保留中文资源和 ARM 架构，启用代码及资源压缩。

## 安装与使用

下载 Release 中的 APK，在车机安装。包名为 `com.shihab.diplay.aion`，版本码为 `4204`；使用与此前 AION 测试版一致的签名，可覆盖升级并保留应用数据。

本车机优先使用车机热点。已确认的 Wi-Fi Direct 问题位于原车固件的 P2P 接口初始化阶段，本版本没有修改 `/vendor` 或修复该固件接口。热点自动控制仍需要系统允许写入设置及固件接口支持。

## 验证记录

- 用户在 2026-11-07 的采样率对照测试中，连续三首歌曲未发现断流或声音挤压，并反馈已修复。
- 随后安装的自动协商版在同一车机读取、声明和实际播放均为 44100 Hz；七分多钟的播放日志中，缓冲耗尽、解码丢弃、写入错误和播放欠载均为零。该运行记录与用户实听记录分别保留。
- 音频及协商相关 31 项测试通过。完整本地检查中 common 1753 项和 home 11 项测试通过；shared 1809 项中 3 项因 Windows 缺少符号链接权限失败，2 项跳过。三个应用的 lint 无 Error/Fatal，构建成功。
- 本次发行仅更新版本标识并重新打包；此前实车结果适用于上述功能代码，发行 APK 的安装和播放未重复进行实车测试。

源码不包含配件身份或 Android 签名密钥。安装包沿用原项目的本地认证方式；原项目的许可证及实验性配件身份说明见 [README](../README.md#local-release-packaging)。
